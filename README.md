# Vakil App ⚖️
A premium legal consultation mobile application connecting users with verified advocates.

## 🚀 Tech Stack
* **Frontend:** Flutter
* **Backend:** Supabase (Database & Chat)
* **Auth & Push Notifications:** Firebase
* **Payment Gateway:** Razorpay / Cashfree (TBD)

## 📂 Project Structure
```text
lib/
 ├── core/          # Theme, constants, API configs
 ├── features/      # Screens & UI (Auth, Home, Booking, Chat)
 ├── models/        # Data models
 ├── providers/     # State management (Riverpod)
 ├── services/      # Firebase, Supabase, API calls
 └── main.dart      # Entry point
